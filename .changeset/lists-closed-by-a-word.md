A list of names in a line a library or the CLI writes closes with a word, `a and b` or `a, b or c`, after a colon too, where about twenty lines listed with bare commas: the settings a Broker's limits leave unset, the subjects a Stream lacks, the Messages handed back, the methods a Fake Provider's Mistake says a path takes (`GET or POST`), the other sites of a refused schema, and the values outside an enum (`is not "public", "internal" or "private"`). A Durable consumer's differences are joined by `; `. A type error that shares a sentence with `generate` is now exactly its line or lines: the `:names` of a path, the Guards a Guard requires earlier and the Providers of a Dependency are listed in the order `generate` lists them, and a refusal `generate` writes once for each header name, Endpoint or refused construct is one type error for each. `generate` lists the Providers of a Dependency in the order its Endpoints list them, no longer sorted by code point.
