# Internals of @cf-loom/contract

How the package's `src/` is split into modules, as [Package layout](../../ARCHITECTURE.md#package-layout) in the root ARCHITECTURE.md requires. The entries `src/index.ts` (`.`) and `src/internal/index.ts` (`./internal`) re-export from the modules' `index.ts`.

The package builds with `lib: ["ES2024", "WebWorker"]` and no Node types: `wire/` reads web-standard `Request`, `Headers`, `URL` and streams, which the WebWorker library declares without a browser window's globals (`window`, `document`, `localStorage`), so nothing in it can lean on a page or on Node.

## Modules

| Module | Holds | Depends on |
| --- | --- | --- |
| `declarations/` | every `define*`, its types and type rules, the runtime consts beside the types (`http`, `element`, Standard Rejections, the reserved codes and the names an Endpoint, Guard or Subscription may not take), Attachments, inference types, predicates, the freeze, the `deprecatedAt` stamp's format, a Message Version's version rule and name in code, an Element's lifecycle and whether it still works, which Visibilities a Service's or an Application's Dependency may reach, and the grammar each kind of name, a Rejection code and a recursion id follows | none (reads the Snapshot's types for `ContractPackage`; type only) |
| `open/` | Open Enums: `openEnum`, the `OpenEnum` type it returns, and `isOpen`, openness marked on the schema's definition, which zod copies into every schema it derives; and `openEnumReader`, an Open Enum's Reader schema, which writes its Unknown case back as its text | none |
| `walker/` | zod schemas to Snapshot nodes; the recursive defs nodes reach through `ref`s; the Not allowed rules judged on walked nodes and slots (open intersections and unions); which string formats SNAPSHOT.md knows; a node's shape without its Neutral annotations, its `allOf` items in shape order; a finite number's digits and power of ten as JavaScript writes it | `open`, `declarations` |
| `written/` | a declaration as written, before any rule judges it: a list, an object part and a map as an author wrote them, whether a list field lists nothing, and a value a map or a received object holds itself, and a value as a sentence or a location names it; the parts a declaration holds schemas in and the schema at each, and `Issue`, one way a value broke its part; a root's declarations gathered through its Groups, each located under its Group and gathered once, where first met, and every Endpoint, Event, Command and Subscription its Groups list; an Endpoint's identity, a Message Version's identity, and its name and version read back from it, an Endpoint's, a Message Version's and a Subscription's Event's identity read back from a text that may be none, and a Message Version as a subject spells it, a path's segments, and an Endpoint's method and segments read from its identity, a `{}` as a param; where a Subscription's Event comes from, the Contract itself or a listed Dependency, and the Service that publishes it; what a Dependency's Provider exports, its Endpoints and Events; the Attachments of an Endpoint or a Guard with their Qualifiers, and the Guards that provide its Context; the Guards some Guards reach through the Guards each lists, at any depth, read from declarations or by a lookup the caller gives; the codes some Endpoints reach, those each lists itself and those the Guards they reach answer, read by lookups the caller gives; the Rejections an Endpoint or Guard answers, found by the code each resolves to, the code, status and message each resolves to, and the Standard Rejections a root resolves | `declarations`, `walker` (type only, for `Path`) |
| `issues/` | a value parsed with its schema, or written back through a Reader schema, zod's failures as cf-loom's issue codes; a party's declared parts, an Endpoint's Input or a Guard's demands, parsed under their fields | `declarations`, `written` |
| `validation/` | every rule `generate` enforces, the valid result, a failure as one line, and a Path written as text; the text parts of a Contract's Endpoints and Guards walked once and judged by every text-part rule `generate` applies, header names included; where a decoded value breaks what its definition promises, a zod failure read as one place and one reason, worded for whoever decodes, and on one line, which `decoding/`, `broker-plan/`, the CLI and `@cf-loom/messaging` share | `declarations`, `walker`, `written` |
| `wire/` | the Wire protocol's rules `serve`, the client and the fakes share, free of Handlers and hosts: the request side, matching a method and path, or a method and a path's decoded segments, to the declared Endpoint that wins them by routing precedence, reading a party's text parts and reading a request's body within `maxBodyBytes`, and a response's or a fake's request's whole, by one reader, a stream that fails told from no JSON; a text part's value from its texts by node and a value as text, a number in plain decimal, which text can travel as a header, a path segment or a query value, a segment encoded and decoded, a party's headers read into values by their nodes, and a Success's or an Input's headers as text or Issues; a received body read whole, a stream that already failed discarded without a throw, and the malformed Issue at the whole of its part, a request's `input.body` or a Message's `body`; the Envelopes and reading one from a received body, the reserved codes with their statuses, `committed` and texts, `Internal error`, the status a Fault travels with, the invalid-input body from Issues and its reader, its `in` and `code` as Open Enums, the schema a Rejection's body is read with, the JSON content type and the `Deprecation` header, written and read back; the response side, a `Response` from a checked Success, a Rejection, the invalid-input Rejection from Issues, a Fault, which never carries a code, or a reserved code, the only Fault that does; the Wire protocol over the Broker: a Message Version's subject, the stream a Service is named after, its durable consumer's name, a camelCase name in kebab-case, which a Subscription's durable consumer and the CLI's file names use, a prefix's grammar, a subject or name with its prefix and whether one carries it, the broker message id, the headers cf-loom sets and a Message's broker headers, which Fact ids, broker message ids and transport headers travel unchanged over NATS, the bytes a Message's broker headers take as nats-core writes them and the most JetStream stores, and those headers read back into its ids and transport headers; a body's JSON from bytes and its bytes from JSON | `declarations`, `open`, `walker`, `written`, `validation` |
| `reading/` | a request as its Provider reads it, in the order of [Over HTTP](../../ARCHITECTURE.md#over-http): what stopped it, its Issues, or its Input parsed | `declarations`, `written`, `issues`, `wire` |
| `snapshot/` | the declared Snapshot of a valid root, each Element and Subscription with its Group, its types, the exported Snapshot's included, and the published Snapshot's, with its tombstones and whether an Element is still declared or a Subscription is removed, and the canonical text of either; whether a text is a semantic version, its parts, and the part of one a caret range keeps fixed; the exported Snapshot cut from a Service's declared or published Snapshot: its exported Endpoints and Events, and the Guards, codes and defs they reach; the Rejections an Endpoint lists itself, read back from its codes; an exported Endpoint's entry, found by identity, and the nodes its text parts are read by; which format a Snapshot names: one this cf-loom reads, a newer one, or no whole number from 1; and an exported Snapshot refused in a format this cf-loom does not read | `declarations`, `walker`, `written`, `validation` |
| `broker-plan/` | the broker plan of a Service's declared Snapshot under a prefix: its stream with the subjects of its Message Versions that are not Retired, when it has any, and the durable consumer of each Subscription and Command Version that is not Retired, with the stream it reads and its subject, keyed by name in code point order; a value read back as that plan, refused unless it has the shape `cf-loom broker-plan --json` prints, its names and subjects carrying its prefix | `declarations`, `walker`, `written`, `validation`, `wire`, `snapshot` (type only) |
| `decoding/` | a `snapshot.json` from the registry decoded by the format it names, as `snapshot/` reads it, into the published Snapshot, in canonical order, failing closed at the first place it breaks: its structure, its identities and versions, the names it uses that it must hold, and the defs that must pass through a node before they lead back to themselves | `declarations`, `walker`, `written`, `validation`, `snapshot` |
| `compatibility/` | the Compatibility Check of a declared Snapshot against its Baseline: each difference on an Element not Retired on both sides, by identity, lifecycle, name and Visibility, a Message Version added against its name's kind and numbering, in what an Endpoint reads and answers (its params by position, query, Input headers with the header text rule, bodies, Success status and headers, and the Rejections it answers), the URLs an Endpoint the Baseline does not declare takes from one kept from it, and in the schemas of its bodies by Position, following `ref`s into both Snapshots' defs, on each Rejection code's status and body, on each Subscription's name and Event, and on a Definitions Package's shared schemas as Messages and its Guards' demands as Input and the codes they answer, as a Change with its class and Verdict, at steps from its site that name a variant's discriminator, in a fixed order; the version bump from the Changes' classes and Verdicts and the peer ranges; the history merge into the published Snapshot at a version | `declarations`, `walker`, `written`, `wire`, `snapshot` |
