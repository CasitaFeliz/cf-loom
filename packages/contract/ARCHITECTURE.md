# Internals of @cf-loom/contract

How the package's `src/` is split into modules, as [Package layout](../../ARCHITECTURE.md#package-layout) in the root ARCHITECTURE.md requires. The entries `src/index.ts` (`.`) and `src/internal/index.ts` (`./internal`) re-export from the modules' `index.ts`.

The package builds with `lib: ["ES2024", "WebWorker"]` and no Node types: `wire/` reads web-standard `Request`, `Headers`, `URL` and streams, which the WebWorker library declares without a browser window's globals (`window`, `document`, `localStorage`), so nothing in it can lean on a page or on Node.

## Modules

| Module | Holds | Depends on |
| --- | --- | --- |
| `declarations/` | every `define*`, its types and type rules, the runtime consts beside the types (`http`, `element`, Standard Rejections, the reserved codes), Attachments, inference types, predicates, the freeze, the `deprecatedAt` stamp's format, a Message Version's version rule and name in code, an Element's lifecycle and whether it still works, and which Visibilities a Service's or an Application's Dependency may reach | none (reads the Snapshot's types for `ContractPackage`; type only) |
| `open/` | Open Enums: `openEnum` and `isOpen`, and `openEnumReader`, an Open Enum's Reader schema, which writes its Unknown case back as its text | none |
| `walker/` | zod schemas to Snapshot nodes; the recursive defs nodes reach through `ref`s; the Not allowed rules judged on walked nodes and slots (open intersections, records keyed by an enum or literal); which string formats SNAPSHOT.md knows; a node's shape without its Neutral annotations, its options in shape order; a finite number's digits and power of ten as JavaScript writes it | `open` |
| `written/` | a declaration as written, before any rule judges it: a list, an object part and a map as an author wrote them, and a value a map or a received object holds itself, and a value as a sentence or a location names it; the parts a declaration holds schemas in and the schema at each, and `Issue`, one way a value broke its part; a root's declarations gathered with their locations, its Events, Commands and Subscriptions included, and its Endpoints in Group order; an Endpoint's identity, a Message Version's identity, and its name and version read back from it, an Endpoint's, a Message Version's and a Subscription's Event's identity read back from a text that may be none, and a Message Version as a subject spells it, a path's segments, and an Endpoint's method and segments read from its identity, a `{}` as a param; the Service whose Event a Subscription receives; the Attachments of an Endpoint or a Guard with their Qualifiers, and the Guards that provide its Context; the Guards some Guards reach through the Guards each lists, at any depth, read from declarations or by a lookup the caller gives; the Rejections an Endpoint or Guard answers, found by the code each resolves to, the code, status and message each resolves to, and the Standard Rejections a root resolves | `declarations`, `walker` (type only, for `Path`) |
| `issues/` | a value parsed with its schema, or written back through a Reader schema, zod's failures as cf-loom's issue codes; a party's declared parts, an Endpoint's Input or a Guard's demands, parsed under their fields | `declarations`, `written` |
| `validation/` | every rule `generate` enforces, the valid result, and a failure as one line; the grammar each kind of name and a Rejection code follows; the text parts of a Contract's Endpoints and Guards walked once and judged by every text-part rule `generate` applies, header names included | `declarations`, `walker`, `written` |
| `wire/` | the Wire protocol's rules `serve`, the client and the fakes share, free of Handlers and hosts: the request side, matching a method and path, or a method and a path's decoded segments, to the declared Endpoint that wins them by routing precedence, reading a party's text parts and reading a request's body within `maxBodyBytes`, and a response's or a fake's request's whole, by one reader, a stream that fails told from no JSON; a text part's value from its texts by node and a value as text, a number in plain decimal, which text can travel as a header, a path segment or a query value, a segment encoded and decoded, a party's headers read into values by their nodes, and a Success's or an Input's headers as text or Issues; a received body read whole, a stream that already failed discarded without a throw, and the malformed Issue at the whole of its part, a request's `input.body` or a Message's `body`; the Envelopes and reading one from a received body, the reserved codes with their statuses, `committed` and texts, `Internal error`, the status a Fault travels with, the invalid-input body from Issues and its reader, its `in` and `code` as Open Enums, the schema a Rejection's body is read with, the JSON content type and the `Deprecation` header, written and read back; the response side, a `Response` from a checked Success, a Rejection, the invalid-input Rejection from Issues, a Fault, which never carries a code, or a reserved code, the only Fault that does; the Wire protocol over the Broker: a Message Version's subject, its durable consumer's name, the broker message id and the headers cf-loom sets; a body's JSON from bytes and its bytes from JSON | `declarations`, `open`, `walker`, `written`, `validation` |
| `reading/` | a request as its Provider reads it, in the order of [Over HTTP](../../ARCHITECTURE.md#over-http): what stopped it, its Issues, or its Input parsed | `declarations`, `written`, `issues`, `wire` |
| `snapshot/` | the declared Snapshot of a valid root, its types, the exported Snapshot's included, and the published Snapshot's, with its tombstones and whether an Element is still declared or a Subscription is removed, and the canonical text of either; whether a text is a semantic version, how two compare, and the part of one a caret range keeps fixed; the exported Snapshot cut from a Service's declared or published Snapshot: its exported Endpoints and Events, and the Guards, codes and defs they reach; the Rejections an Endpoint lists itself, read back from its codes; an exported Endpoint's entry, found by identity, and the nodes its text parts are read by | `declarations`, `walker`, `written`, `validation` |
| `decoding/` | a `snapshot.json` from the registry decoded by the format it names into the published Snapshot, in canonical order, failing closed at the first place it breaks: its structure, its identities and versions, the names it uses that it must hold, and the alias defs that must lead to a node | `declarations`, `walker`, `written`, `snapshot` |
| `compatibility/` | the Compatibility Check of a declared Snapshot against its Baseline and the dependency graph: each difference on an Element not Retired on both sides, by identity, lifecycle, name and Visibility, a retirement or a narrowing with the Dependencies it would leave without the Element, a Message Version added against its name's kind and numbering, in what an Endpoint reads and answers (its params by position, query, Input headers with the header text rule, bodies, Success status and headers, and the Rejections it answers), the URLs an Endpoint the Baseline does not declare takes from one kept from it, and in the schemas of its bodies by Position, following `ref`s into both Snapshots' defs, on each Rejection code's status and body, on each Subscription's name and Event, and on a Definitions Package's shared schemas in every Position and its Guards' demands as Input and the codes they answer, as a Change with its class and whether it needs an Approval, in a fixed order; the version bump from the Changes' classes and the peer ranges; the history merge into the published Snapshot at a version | `declarations`, `walker`, `written`, `wire`, `snapshot` |
