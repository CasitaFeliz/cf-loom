# Contributing

Until cf-loom reaches 1.0.0, its design is still changing, and only its maintainers change the code.

- **Issues are welcome**: a bug, a question, or something cf-loom should derive from a Contract. Open one on GitHub.
- **Pull requests are not taken before 1.0.0**: one opened from outside is closed. Open an issue instead.
- **A vulnerability is never an issue**: report it as [SECURITY.md](SECURITY.md) says.

How the maintainers turn an issue into code is in [WORKFLOW.md](WORKFLOW.md).
